# 验证：量了才算完成

## 三层判据

1. **几何**（`kind=geom`）：体积、包围盒、表面积
2. **位置**（`kind=pos`）：孔距、孔到边、中心坐标
3. **关系**（`kind=rel`）：壁厚、间隙、面距

## 标准动作

```text
f = nx_measure(target=last)          # 拿实测 facts
nx_assert spec={"kind":"geom","measure":{"type":"volume"},
                "expect":{"value":12345.6,"tol":0.5}} facts=<上一步 facts>
```

- `expect` 填图纸/理论值；`tol` 用绝对容差（mm / mm³）。
- `pass=false` 时不许说完成：回到预检/修改，或 restore 快照。
- 没有图纸值时，可用"改前 vs 改后"的 delta 做回归判据（改前量一次存进经验库）。

## 常见不达标

| 现象 | 先查 |
|---|---|
| 体积差很多 | 布尔没生效/多建了一个体 |
| 包围盒尺寸对不上 | 单位不是 mm，或原点偏移 |
| 孔位置偏 | 图纸基准边取错，或方向向量符号反了 |
| 面数异常增加 | 布尔产生碎片面，检查是否两体不相交 |
